# KieliValmis R4M preview candidate

Preview-only landing candidate for the organization repository `Floently/floently-finnish`. It does not replace the current root landing page.

Locked choices:
- the user-approved K + flowing-wave logo geometry is preserved and must not be redesigned
- the website header uses the approved standalone symbol plus live near-white `KieliValmis` text and a tiny `by Floently` endorsement for dark-background contrast and responsive sizing
- the rounded-square approved mark remains the source direction for the later app/store icon; `by Floently` is not baked into the app icon
- mobile hero heading target 25.5–28 px; desktop 39–48 px
- human-centered AI-generated photographic hero with visible disclosure, embedded WebP XMP provenance, a provenance sidecar, and Schema.org `ImageObject` metadata
- subtle CSS-only image drift, waveform and feedback pulse, disabled/reduced under `prefers-reduced-motion`
- 20 complete initial landing-page locale dictionaries with Arabic, Persian and Urdu RTL handling
- Kurdish (`ku`) is currently treated as Kurmanji Latin/LTR pending explicit audit against the existing app locale

Translation status: all 20 landing dictionaries are structurally complete, but this is an initial translation pack. Language-by-language native-quality review is still required before public-domain promotion or freezing the app rebrand translation pack.

This is not yet the final multilingual public site: localized legal/support routes, localized SEO metadata/routes, canonical/hreflang generation, and translation QA remain required before domain promotion.
