# Material Audit Criteria

The agent must use all of the following criteria.

## Technical criteria
- schema explicitness
- validator coverage
- loader clarity
- manifest/index clarity
- active runtime compatibility
- conversion determinism
- versionability
- maintainability
- deployability
- reproducibility

## Material quality criteria
- usefulness for actual Finnish learners
- YKI realism
- professional authenticity
- phrase/chunk value
- grammar pattern usefulness
- vocabulary usefulness in context
- spoken-language relevance
- CEFR/YKI progression support

## Learning-science criteria
- retrieval-practice friendliness
- spaced-review friendliness
- corrective-feedback suitability
- productive-task support
- confidence-calibration support
- self-regulated-learning support
- transfer-to-real-life support

## Operational criteria
- duplication burden
- stale/generated clutter burden
- offline-vs-runtime separation
- ease of publishing into the runtime bank
- risk of multi-truth drift
