# Evidence Notes

The adapted architecture is designed around a governed loop:
Diagnose -> Learn -> Retrieve -> Produce -> Correct -> Schedule -> Review.

Design choices reflected in this pack:
- Retrieval practice and spaced review are treated as core review mechanics.
- Self-regulated learning is supported through onboarding intent capture, weekly cadence, and visible progress state.
- Corrective feedback is immediate for short objective tasks and summarized for longer production tasks.
- Speaking support is assistive rather than authoritative.
- Accessibility is improved through larger controls, calmer layouts, and explicit state.
