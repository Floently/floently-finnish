Support

Last updated: 2026-08-08

Need help with KieliValmis? Contact support@floently.com. KieliValmis is a Floently product by Komplyint Oy, so the existing Floently support address remains valid during the rebrand.

What to include

  • Your account email address.
  • The device and platform you are using: web, iOS or Android.
  • A short description of the problem.
  • Screenshots or error messages when available.

Common support topics

  • Sign-in or Google login issues.
  • Subscription, purchase restoration or access problems.
  • YKI practice, speaking, grammar, vocabulary or roleplay problems.
  • Report/export problems.
  • Account deletion or privacy requests.

Existing users

KieliValmis is the new customer-facing identity for the existing Finnish-learning product. Existing users should continue using the same account. Do not create a second account merely because the product name has changed.
