# Adoption Guide

1. Copy this batch into the repo root.
2. Keep the real engine repo as the source of truth for `engine/`.
3. Replace old duplicated client screens with the new route entrypoints and screen set in this batch.
4. Replace old backend route registration with `apps/backend/api/router.py`.
5. Merge or archive legacy donor files that now duplicate these responsibilities.
6. Keep any existing content bank or accepted card artifacts unless you intentionally regenerate them.
